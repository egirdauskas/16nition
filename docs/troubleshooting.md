# Troubleshooting

| Problem | Fix |
|---|---|
| The game will not install: "App not installed" or "package conflicts" | An original or differently signed FIFA 16 is installed. Use **Prepare game** again: 16NITION offers to remove it first. |
| The APK is refused | Only the original EA-signed 3.2.113645 and 3.0.112594 APKs are accepted. Check the version, and that the file is not already modified. |
| Expansion import fails | Select both the `main.13` and the matching `patch` OBB. Re-copy them if a checksum fails; the file is incomplete or modified. |
| The game does not show up on an emulator | The emulator lacks 32-bit ARM support (for example the MuMu Android 15 player). Use a [tested emulator](installation.md#tested-devices). |
| The game stops at the loading screen | Close the game and start it again with **Play** in 16NITION. |
| The welcome tutorial appears again | The club has not saved progress yet. Open Seasons or Tournaments once; after that the game starts at the main menu. |
| "Match active" when exporting or switching clubs | Finish or quit the current match, then try again. |
| A simulated match seems stuck | Close the game and press **Play** again. The interrupted match is rolled back and nothing is lost or paid twice. |
| I reinstalled 16NITION and the game must be replaced | The device signing key was lost with 16NITION's data. Import your exported clubs and prepare the game again. Always export before uninstalling. |

## Reporting a problem

Note the 16NITION version (Android Settings → Apps → 16NITION), the game version, and the device
or emulator with its Android version. Steps that reproduce the problem help
most.
