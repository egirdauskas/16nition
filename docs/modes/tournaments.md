# Tournaments

Knockout cups with fixed entry rules. Five cups are available at any time,
each as often as you like.

## Format

- 16 teams, 4 rounds (Round of 16, quarter-final, semi-final, final),
  6-minute matches.
- Lose a match and the run ends. You can enter again right away.
- Opponents are drawn from the real clubs in the game's database.
- You can play or simulate each match. If you edit your squad during a run,
  the simulation uses the edited squad.

## Cups

| Cup | Difficulty | Entry requirement |
|---|---|---|
| Starter Cup | Amateur | None |
| Silver Shield | Semi-Pro | Only silver players in XI and subs; chemistry 75+ |
| Bronze Challenge | Professional | Only bronze players in XI and subs |
| Champions Trophy | World Class | None |
| Brazil Cup | World Class | At least 7 Brazilian players in the starting XI |

Each cup has its own trophy design.

## Rewards

| When | Reward |
|---|---|
| Every match | Coins and XP for the cup's difficulty and the result, as in Seasons, plus one untradeable pack |
| Winning the cup | Winner coins, **every** time you win |
| Winning a cup for the first time | A one-time bonus: packs, and in the Brazil Cup a Carnival David Luiz card |

Exact amounts are in the [Tournaments reference](../reference/tournaments.md).
The first-win bonus is given only if you had no trophy for that cup when the
run started. Trophies from earlier versions count.
